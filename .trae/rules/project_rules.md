# Project guidance

Use the root `AGENTS.md` for ownership, task identity and execution routing.
Select a relevant skill under `.agents/skills/` when the task needs its business
method; read only the referenced detail needed for that task. Native local work
and direct package tools do not require a skill first.

Submodule code follows its own `AGENTS.md`. Trae stubs route to canonical skills;
ModelScope's generated Trae package is maintained by the shared generator.
