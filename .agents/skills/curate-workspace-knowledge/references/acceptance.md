# Acceptance

The consumer regression exercises the installed package through the real CLI:

- minimal Markdown capture followed by public-copy preparation;
- unchanged candidate bytes and idempotent pending identity;
- invalid Markdown blocked without creating a public document;
- command help and rejection of retired YAML promotion verbs.

Run:

```bash
uv run python -B -m unittest discover -s .agents/skills/curate-workspace-knowledge/tests
```

Network submission, real classifier/recall and GitHub merge checks belong to
the knowledge package's integration evidence and are not implied by these tests.
